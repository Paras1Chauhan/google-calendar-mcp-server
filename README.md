## 📖 About

A Google Calendar MCP server that lets Claude AI create, read, update, and delete calendar events using natural language — integrated with Claude Desktop via the Model Context Protocol.

## ✨ Features

- Create, read, update & delete Google Calendar events
- Natural language event scheduling via Claude AI
- OAuth2 authentication with Google APIs
- Supports recurring events, time zones & reminders
- Fully MCP protocol compliant with stdio transport
- Works with Claude Desktop on Windows & Mac

## 🛠️ Tech Stack

- **TypeScript**
- **Node.js**
- **MCP SDK**
- **Google Calendar API**
- **OAuth2**
- **Zod**

## 🚀 Getting Started

```bash
git clone https://github.com/Paras1Chauhan/google-calendar-mcp-server.git
cd google-calendar-mcp-server && npm install
Set up Google OAuth2 credentials and add to .env
npm run build
Add to Claude Desktop config and restart Claude
```
